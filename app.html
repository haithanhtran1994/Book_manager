📚 Book Manager

Mở file .xlsx / .csv để bắt đầu, hoặc tạo file mới.

iPhone: Safari → nút Chia sẻ → “Thêm vào MH chính” để dùng như app.

File chưa có sheet nào. Bấm “＋ Sheet” để tạo.
Sheet này chưa có danh sách Status. Tạo danh sách Status trước khi thêm item.

Nhập dải như 1-5 hoặc 1,2,3,10-12 để thêm nhiều hàng cùng lúc: Item sẽ là Prefix_1…Prefix_5, cùng Status đã chọn. STT đã tồn tại sẽ bị bỏ qua. Bảng luôn tự xếp theo STT tăng dần.
